# Leaf Guide HK - Preliminary Website

A small Vite + React + Tailwind site that lists 10 Hong Kong hospitality businesses with sustainability scores and Leaf ratings.

## Quick start

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal.

## What is inside

- React 18 + Vite
- Tailwind CSS
- Simple filter and sort
- Cards with score breakdown, badges, and evidence toggle
- Data is in `src/data.js`

## Edit the data

Add or change entries in `src/data.js`.
